# Babsis Food House Business Website

A professional restaurant business website for **Babsis Food House** with a polished layout, menu showcase, order section, dashboard, and location details.

## Included sections

- Hero section with strong branding and CTA buttons
- About section for business introduction
- Menu showcase for featured dishes
- Orders section for order management presentation
- Dashboard section for sales and performance overview
- Visit / Google Maps section for easy customer directions
- Responsive layout for mobile and desktop

## Files

- `index.html` – main page structure
- `styles.css` – visual styling, layout, colors, and animations
- `script.js` – small interactive behavior

## How to preview locally

Open the website in a browser using a local web server.

### Option 1: Python HTTP server

Run this in the project folder:

```bash
py -m http.server 8000
```

Then open:

```text
http://127.0.0.1:8000
```

### Option 2: VS Code Live Server

If you have the **Live Server** extension installed, right-click `index.html` and choose **Open with Live Server**.

## Notes

- The Google Maps link is included in the visit section.
- The site is designed to be easy to present to the restaurant owner and can be expanded later with real order forms, reservation tools, and more branding.
